How the questions are built

Every question on this site traces back to a specific passage in the unit's Student Guide and to the enabling objective it supports. The process for each unit:

  1. Start from the Student Guide. The guide is the source of truth. Questions are written in its language, on its emphasized material — the objectives listed at the start of each chapter, the review questions, the numbers and rules it repeats.
  2. Verify every answer against the text. Each keyed answer is confirmed against the guide, and each rationale quotes or cites the supporting passage with its chapter and objective. Questions that cannot be grounded are cut.
  3. Season with the gouge. Class gouge decks and shared question banks are used to decide what to emphasize and to seed some items — rewritten and re-verified, never copied blindly.
  4. Drop the trivia. A periodic audit removes questions that only test obscure details, and replaces them with concept and application questions that mirror how the real tests are written.

How to use the site

  1. Pick a unit from the NIFE – Academics menu at the top, or from the cards below.
  2. Choose a test. Tests 1–3 (A–C) run Easy → Medium → Hard on the full unit, 50 questions each. Chapter and topic reviews are 30-question drills on one block of material.
  3. Choose a mode. Exam Mode grades at the end, like the real test. Practice Mode grades each question on the spot and shows the rationale right away.
  4. Optional dump sheet. Start with a 5-minute timer to write down formulas, mnemonics, and numbers from memory before the questions appear — good rehearsal for test day.
  5. Review, then retake what you missed. Results show every missed question with the correct answer, the reasoning, and the Student Guide reference, plus a breakdown by chapter. "Retake Missed Only" drills just those questions.
  6. Use the extras. Flashcards for mnemonics and must-know numbers, system diagrams to name parts, and the SET AI drill for altimetry problems.

Questions and answer choices shuffle every attempt. Your scores are saved in this browser only — nothing is sent anywhere, and switching devices starts fresh. The site works offline once you have visited it.
